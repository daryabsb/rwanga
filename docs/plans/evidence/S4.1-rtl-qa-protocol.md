## 0. Two surfaces, two truths — read this before judging anything

The convention's indent magnitudes (2.0in / 1.5in / 1.0in) are **page truth**, and page truth lives
in **Print Preview and PDF**, not in Flow. Flow is a *continuous drafting surface* by locked
doctrine (Flow continuous-drafting doctrine, Option A — no page seams, no paginated geometry), and
it deliberately centres character / dialogue / parenthetical instead of indenting them
(`editor-prosemirror.css:1145-1162`: `text-align: center`, `margin: 0 auto`, symmetric
`--dialogue-side-margin` / `--parenthetical-side-margin`).

**Therefore:**

| Surface | What the convention binds | What a Phase-4 verdict may assert |
|---|---|---|
| **Flow** (`.rga-block-*`) | direction only — the *mirror*, not the magnitudes | `text-align: start/end` resolves to the correct physical side under `dir=rtl`; symmetric blocks stay symmetric; nothing collapses flush to a margin |
| **Print Preview** (`.rga-print-block-*`) | the full law — magnitudes **and** direction | exact inch offsets from the reading-start edge, to ±1 mm |
| **PDF export** | must equal Print Preview | same numbers as the Preview run, byte-for-byte contract |

A Flow block that is centred is **not** an RTL-04…09 failure. Judging Flow against print indents
would manufacture false reds and, worse, invite a "fix" that violates the Flow doctrine. **Any spec
written for RTL-04…RTL-09 must state which surface it measures, in its header.**

  numerals (`٣`) alongside Latin tokens — RTL-12's raw material exists without authoring anything.

## 0.2 How to measure an inch

The page element's rendered width is the scale. In a Print Preview page:

```js
const pxPerIn = pageRect.width / paperWidthIn;      // paperWidthIn = 8.5 for Letter, 8.27 for A4
const startEdge = dir === 'rtl' ? pageRect.right - marginStartPx : pageRect.left + marginStartPx;
const inset     = dir === 'rtl' ? (startEdge - blockRect.right) : (blockRect.left - startEdge);
// PASS when: Math.abs(inset / pxPerIn - expectedIn) <= 0.04   // 0.04in ≈ 1mm
```

Tolerance **±1 mm (±0.04 in)** everywhere unless a row says otherwise — tight enough to catch a
collapsed indent, loose enough to survive sub-pixel rounding and font metrics.

**Reference magnitudes** (`editor-prosemirror.css:2484-2518` + `layout-profile.js:68-78`):

| Block | Indent from reading-start | CSS box max-width | Text column (`blockWidthsIn`) |
|---|---|---|---|
| sceneHeading | 0 (flush start) | full body | 6.0in |
| action | 0 (flush start) | full body | 6.0in |
| shot | 0 (flush start) | full body | 6.0in |
| character | **2.0in** | — | 3.5in |
| parenthetical | **1.5in** | 3.5in | 2.0in (= 3.5 − 1.5) |
| dialogue | **1.0in** | 3.5in | 2.5in (= 3.5 − 1.0) |
| transition | flush **reading-end** | full body | 6.0in |

### RTL-05 — RTL dialogue alignment correct

|---|---|
